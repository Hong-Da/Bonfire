# v0.2.3

- 日期：2026-10-11

- 摘要：同步失败显示原因与解决办法，连不上目标时自动重试（5 分钟、15 分钟、1 小时），可忽略连不上、超过总大小、单文件超限三类问题

## 新增

- 同步失败的原因：连不上目标、令牌或密码不对、找不到仓库或文件夹、仓库是公开的、超过总大小上限、仓库文件超过单文件上限、读取本机文件失败；卡片上显示原因、解决办法与详细信息。
- 自动重试：连不上目标（网络、服务器，或移动硬盘、局域网共享没连上）时，非手动同步的目标在 5 分钟、15 分钟、1 小时后各重试一次，卡片显示下次重试时间；令牌错误、公开仓库、超过上限等重试解决不了的问题不重试。
- 忽略问题：卡片上点“忽略这类问题”，或在编辑目标中勾选。可忽略：连不上目标（不再算作同步有问题，仍自动重试）、超过总大小上限（照常同步）、有文件超过单文件上限被排除（不再提醒）。`bonfire sync add --ignore network,size,excluded`。

## 修改

- “每个游戏备份到了哪里”不把已忽略的失败算作问题；`bonfire sync list` 显示下次重试时间。
