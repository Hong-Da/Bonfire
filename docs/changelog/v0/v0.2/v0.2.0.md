# v0.2.0

- 日期：2026-10-11
- 对应提交：标签 `v0.2.0`（比较基准：`v0.1.0`）
- 摘要：同步备份：把仓库、最新存档与截图同步到 GitHub、Gitee、WebDAV、网盘、远程目录与指定目录，带大小检查、自动同步与从远程恢复；重启后游戏库不再保留勾选

## 新增

- **同步备份（SYNC，REQ-015）**：侧栏新增“同步”页与 `bonfire sync` 命令。
  - 目标：GitHub、Gitee（内置 Git，访问令牌，不需要安装 Git）、WebDAV（坚果云、Nextcloud、群晖、AList 等）、网盘（WebDAV 或网盘客户端的同步文件夹）、远程目录（局域网共享）、指定目录；可同时添加多个目标。
  - 内容：完整仓库（全部历史，可从远程恢复，加密仓库远程也是加密的）/ 最新存档（网页或网盘里直接可见）/ 只同步截图；可另选截图与篝火设置（不含密钥、令牌与密码）。
  - 大小检查：单文件超过上限的文件不上传并列出；同步后超过总大小 80% 时提醒，会超过上限时不同步并给出办法；默认 GitHub 100 MB / 1 GB、Gitee 50 MB / 500 MB。首次同步分批推送；公开的 GitHub / Gitee 仓库不同步；可压缩远程仓库。
  - 增量上传，中途失败不会让远程处于不一致的状态；每次备份后、每天或每隔几小时在后台自动同步。
  - 每个游戏备份到了哪里一目了然；换电脑时从远程把完整仓库下载到空文件夹，可直接改为篝火的仓库并套用远程设置。
  - 令牌与密码用 Windows 数据保护保存在本机，不写入配置文件与日志。

## 修改

- 游戏库勾选：重启篝火后全部不勾选，同一次运行中切换页面时保留；设置页去掉“记住勾选的游戏”（配置项 `general.remember_selection` 不再使用）。
