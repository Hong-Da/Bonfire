# v0.2.1

- 日期：2026-10-11
- 对应提交：标签 `v0.2.1`（比较基准：`v0.2.0`）
- 摘要：修复 Gitee 用户名不是登录名时推送被拒（403）；添加同步目标后询问是否立即同步

## 修改

- 添加同步目标后询问“现在同步一次吗？”，确认后先显示同步预览。
- Gitee 用户名可以留空：篝火用令牌查到登录名；界面与 `bonfire sync add --user` 的说明随之更新。

## 修复

- Gitee 同步失败“Git：request failed with status code: 403”：用户名填的不是登录名（个人空间地址 gitee.com/<名称> 中的名称）时被 Gitee 拒绝。现在依次尝试令牌对应的登录名、填写的用户名、仓库地址中的所有者；仍被拒绝时提示检查令牌权限与用户名。
