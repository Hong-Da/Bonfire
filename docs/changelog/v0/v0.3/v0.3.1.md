## 修改

- 总览页操作记录默认只显示最近一周，可切换为最近一个月或全部（180 天）；一周内没有记录时可以一键看最近一个月。`bonfire activity --days N`。
- 失败记录的处理状态：之后同一操作成功了（如同一游戏再次备份成功、同一目标再次同步成功）自动显示为“已处理”（灰色、空心圆点）；其他方式处理过的可以点“标为已处理”。
- “失败”筛选改为“未处理的失败”，数字只计未处理的；手动标为已处理的备份失败不再显示红点。
