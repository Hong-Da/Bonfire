- 日期：2026-10-11

- 摘要：新增总览页：存档的三道防线、待处理与红点 / 系统通知、存储统计、本机操作记录、全部游戏的截图与磁盘对比与一键收集 / 写回

## 新增

- **总览页（OV，REQ-016）**：导航第一项（启动后仍显示游戏库）。
  - 存档的三道防线：磁盘上的存档 → 篝火仓库 → 远程，一句话结论；连线实线为已接上，琥珀色虚线为有缺口（没备份、没同步），红色虚线为失败。
  - 待处理：同步失败、备份失败（如存档被占用）、有新存档没备份、待确认的存档位置、没同步到远程、可清理空间等，每条一个直接解决的按钮，可以“稍后提醒”（情况变化时重新出现）。
  - 红点：有需要处理的失败时，导航“总览”显示红色数字，任务栏图标与托盘图标显示红点（关闭到托盘时也有）。
  - 系统通知：同步失败、自动备份失败时，篝火窗口不在前台则弹出 Windows 通知，同一个问题只通知一次；设置“失败通知”中可以关闭。
  - 存储：仓库占用（存档快照 / 截图 / 其他）、去重与压缩节省、可清理、近 30 天增长曲线、最占空间的游戏、远程目标状态、所在磁盘剩余空间。
  - 截图与磁盘：对比全部游戏（只读），一键收集磁盘上的新截图、一键把图库中有而磁盘上没有的截图写回（不覆盖）；存档不提供一键写回（那就是恢复，请在游戏详情中预览后恢复）。
  - 操作记录：本机最近 180 天的备份、恢复、分支与标签、同步、截图、导入导出、清理与维护，失败的带原因；按类型、游戏筛选，可搜索；第一次打开时补出以前的历史。
- 命令行：`bonfire activity`、`bonfire stats`、`bonfire shots compare [--write-back]`。
