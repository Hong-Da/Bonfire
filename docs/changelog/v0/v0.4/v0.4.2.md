# v0.4.2

- 日期：2026-10-11
- 对应提交：标签 `v0.4.2`（比较基准：`v0.4.1`）
- 摘要：设置中新增恢复出厂设置（输入确认文字才执行，可选删除备份仓库）；去掉“重新运行向导”；功能导览“去试试”后可以继续

## 新增

- **恢复出厂设置**（设置页最后一项）：
  - 列出将要清除的内容与大小：全部设置、自定义存档规则、界面状态、记住的仓库密码与同步的访问令牌、缓存、操作记录、日志、窗口数据。
  - 列出保留不动的内容：备份仓库（位置与大小）、游戏的存档文件、远程同步的备份；说明重新运行向导时选同一个仓库位置即可继续使用备份，加密仓库需要重新输入密码。
  - 可勾选“同时删除备份仓库”，红色提示无法恢复；只删除篝火仓库自己的文件。
  - 必须输入“恢复出厂设置”（删除仓库时输入“删除全部备份”）按钮才可用；执行后程序重启进入首次运行向导。
  - 命令行：`bonfire reset --confirm 恢复出厂设置 [--delete-repo]`，不带 `--confirm` 只列出要清除的内容。

## 修改

- 设置中去掉“重新运行向导”（首次运行向导不变）。
- 功能导览点“去试试”后不再直接关闭：收起到右下角“继续篝火入门（n/8）”，点击从下一张继续。
