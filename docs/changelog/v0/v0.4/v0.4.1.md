# v0.4.1

- 日期：2026-10-11
- 对应提交：标签 `v0.4.1`（比较基准：`v0.4.0`）
- 摘要：界面优化：导航、顶部栏、搜索框、游戏库列宽、设置页宽度、同步页按钮与图库（全选 / 反选、悬停、列表、大图翻页、缩进对齐）共 12 处，不改风格

## 修改

各页通用：
1. 导航栏当前页加淡色底、文字加粗。
2. 各页顶部栏统一高度，切换页面时标题不再跳动。
3. 游戏库、图库的搜索框固定 360 px、靠右放，宽屏时不再铺满整行。
4. 游戏库名称、状态、上次备份、大小四列按比例分配，宽屏时中间不再空一大段。
5. 设置页内容限制在 1080 px 并居中。
6. 空状态的说明按正常宽度换行，标题加粗。
7. 同步页每个目标上的“立即同步”改为次要按钮，页面只保留一个主要按钮“添加同步目标”。

图库：
- G1 分组标题旁的“全选 / 反选”平时隐藏，悬停标题、这一组有勾选或已折叠时显示。
- G2 鼠标停在缩略图上时出现淡色描边。
- G3 列表视图文件名列更宽，来源、尺寸等短字段不换行。
- G4 查看大图时的上一张 / 下一张改为圆形半透明按钮，离图片更近。
- G5 缩略图与列表向右缩进，与分组标题中的游戏名对齐。
