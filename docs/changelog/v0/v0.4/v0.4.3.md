# v0.4.3

- 日期：2026-10-11
- 对应提交：标签 `v0.4.3`（比较基准：`v0.4.2`）
- 摘要：pack.bat 可选免安装包（默认）、安装包、迁移包，所有包名带版本号与运行环境（如 win-x64）

## 新增

- **免安装包**：`Bonfire_<版本>_win-x64_portable.zip`，解压后双击 `Bonfire.exe` 即可使用，设置、备份仓库与日志保存在同目录的 `data` 中，可放在 U 盘；附使用说明；打包时可选带上数据。

## 修改

- `pack.bat` 选择包的类型（`--type portable|setup|migrate|all`，交互时出现菜单，默认免安装包）。
- 所有发布包的文件名都带版本号与运行环境：免安装包 `_win-x64_portable.zip`、安装包 `_win-x64_setup.exe`、迁移包 `_win-x64_migrate_<日期>.zip`；运行环境从构建出的程序读取（x64 / x86 / arm64）。
- 迁移包与带数据的免安装包会一起带上自定义规则；始终不带记住的密码与同步令牌、缓存与窗口数据。
