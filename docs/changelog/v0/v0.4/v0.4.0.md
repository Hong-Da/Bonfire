# v0.4.0

- 日期：2026-10-11
- 对应提交：标签 `v0.4.0`（比较基准：`v0.3.3`）
- 摘要：首次运行向导改版：可从远程取回以前的备份和设置、新增自动备份一步；新增功能导览；可在设置中重新运行向导

## 新增

- **从远程获取（向导第 2 步，可跳过）**：提示“如果之前用篝火同步过备份，可以从那里取回全部存档历史和篝火设置”。支持 GitHub、Gitee、WebDAV、网盘、远程目录、指定目录；下载完整仓库到空文件夹，带回当时的篝火设置并预填后面的步骤；仓库加密时完成后输入密码；可选“以后继续同步到这里”。
- **自动备份（向导新步骤）**：退出游戏后自动备份（默认开）、存档变化后自动备份、关闭窗口时留在托盘（默认开）。
- **功能导览**：8 个常用功能（扫描并加入游戏、备份与备注、回到以前的存档、自动备份、截图图库、同步到远程、总览与红点、分享与导入存档），每张可“去试试”；首次运行后第一次进入游戏库时弹出；升级的用户在总览看到一次提示。
- **设置 · 帮助**：重新运行向导（按当前设置预填，仓库位置不变，完成后可重新扫描）、查看功能导览。
