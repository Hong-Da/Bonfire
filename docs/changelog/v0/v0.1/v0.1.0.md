# v0.1.0

- 日期：2026-10-11
- 对应提交：标签 `v0.1.0`（初始版本，无比较基准）
- 摘要：初始版本：快照式游戏存档备份、恢复与历史，七个平台的存档发现，桌面应用与命令行，截图相册，导入导出，自动备份与历史清理，可选仓库加密

## 新增

- **存档发现（GAME）**：扫描 Steam、Epic、GOG、Ubisoft Connect、EA app、Xbox / Microsoft Store、Battle.net，按 Ludusavi 规则库（2 万多款游戏）定位存档，规则库没有的游戏启发式探测后由用户确认；手动添加游戏与存档位置；获取中文名、封面、游玩时长等信息。
- **更新检测（SCAN）**：按文件元数据快速判断，必要时校验内容哈希；状态与差异。
- **备份（BAK）**：内容寻址、FastCDC 分块去重、zstd 压缩；多文件并行入库；备份方案；逐游戏备注。
- **历史（HIS）**：分支图、快照差异、分支与标签、备注修改与搜索、删除快照（含 Ctrl / Shift 多选删除，删除前检查与安全确认）、每台电脑的主存档。
- **恢复（RES）**：恢复前预览、保护快照、失败回滚、一键撤销；游戏运行时阻止恢复。
- **导入导出（XFER）**：导出存档文件、篝火包（带校验值）与 zip；导入篝火包、下载的存档（zip / 7z / rar / 文件夹）。
- **截图（SHOT）**：收集 Steam、Windows 游戏栏与指定文件夹的截图，相册、回收站、与快照时间线关联、导出。
- **自动备份与运行检测（AUTO）**：定时、存档变化后、退出游戏后自动备份；按安装目录或“游戏程序”检测游戏运行，运行中的游戏推迟到退出后再备份；托盘常驻。
- **历史清理（CLEAN）**：保留策略（最近 N 个、每天 / 每周 1 个）、标签永不清理、垃圾回收、可释放空间的来源明细、规则说明与安全提示。
- **加密与被占用文件（SEC）**：仓库可选 AES-256-GCM 加密（Argon2id），本机记住密码；存档被游戏占用时提示，可选 Windows 卷影复制读取。
- **维护（MAINT）**：`fsck` 校验、重建索引、规则库更新、配置文件。
- **桌面界面（UI）**：首次运行向导、设置、中英文、明 / 暗主题、NSIS 安装包（卸载保留数据）。
- **收尾**：打包迁移脚本 `pack.bat`、迁移说明 `docs/migration.md`、项目专属 skill（bonfire-cli、bonfire-test、bonfire-update）。
