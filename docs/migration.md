# 篝火 Bonfire 迁移与部署

篝火是 Windows 桌面程序，部署就是运行安装包。本文说明怎样安装，以及怎样把备份历史搬到另一台电脑。

## 安装

运行 `Bonfire_<版本>_x64-setup.exe`：

- 按当前用户安装，不需要管理员权限；默认装在 `%LOCALAPPDATA%\Bonfire`，可以改。
- 安装后从开始菜单启动“Bonfire”，第一次启动进入配置向导。
- 数据（配置、备份仓库、日志、缓存）都在 `<安装目录>\data`。卸载时会询问是否同时删除 `data`（默认保留，删除前再确认一次）；选择保留时，重新安装或升级后备份历史仍在。升级安装不会询问、也不删除。**已同步到 GitHub、Gitee、WebDAV、网盘或其他文件夹的远程备份不会被删除**；仓库位置改到 `data` 以外时，那里的仓库也不会被删除。静默卸载（`uninstall.exe /S`）保留数据，加 `/DELETEDATA` 时删除。
- 命令行在 `<安装目录>\cli\bonfire.exe`，与桌面程序共用 `data`。

升级：直接运行新版本的安装包覆盖安装，`data` 保留。

## 搬到新电脑

有三种办法，按方便程度排列：

### 一、仓库放在网盘同步目录（推荐长期使用）

在“设置 → 存档仓库”把仓库位置改到网盘同步目录（如 OneDrive）。新电脑装好篝火后，在配置向导的“仓库位置”选同一个目录即可，备份历史、分支和备注都会出现。两台电脑轮流使用时，每台电脑有自己的“主存档”路线，互不覆盖。

建议同时开启“设置 → 仓库加密”，网盘上的数据只有输入密码才能读取。

### 二、用打包迁移脚本（一次性搬家）

在开发环境或已有安装包的电脑上运行根目录的 `pack.bat`：

```bat
pack.bat                                      :: 交互：询问数据目录和要包含的内容，列出大小后确认
pack.bat --no-data --yes                      :: 只打包安装包与本说明
pack.bat --data "%LOCALAPPDATA%\Bonfire\data" --include config+repo --yes
```

- 输出 `dist\Bonfire_<版本>_<日期>.zip`，包含安装包、本说明，以及选中的 `data\config.toml`（配置）、`data\repo`（备份仓库）、`data\logs`（日志）。
- 默认不包含任何数据，需要时逐项选择；打包前列出每项大小和合计，确认后才开始。
- 始终不包含：本机记住的密码（`keys\`，与这台电脑的 Windows 账户绑定，换电脑无效）、缓存（`cache\`，新电脑上自动重建）。

在新电脑上：

1. 解压 zip，运行安装包。
2. 包含数据时，**先不要启动篝火**，把解压出来的 `data` 文件夹复制到安装目录（默认 `%LOCALAPPDATA%\Bonfire\data`），再启动。
3. 配置中的仓库位置如果是旧电脑上的其他盘符，第一次启动后在“设置 → 存档仓库”改到实际位置。
4. 加密的仓库：启动时输入密码，可以勾选在这台电脑上记住。

### 三、导出篝火包

只搬几个游戏时，在游戏库选中游戏 →“导出所选游戏”生成篝火包（`.bonfire`），在新电脑的游戏库“导入”。篝火包包含完整的快照历史、分支、标签和截图，并带有校验值，导入时检查是否被改动。篝火包不加密。

## 新电脑上要注意

- **存档路径不同**：游戏装在不同位置或 Windows 用户名不同时，扫描会按新电脑的实际位置识别存档；手动添加的游戏需要在详情页确认存档位置。
- **恢复前先看清楚**：恢复会改写这台电脑上的存档，恢复前自动生成保护快照，可以一键撤销。
- **存档安全保护**按电脑名区分本机备份：在新电脑上，旧电脑备份的快照不算“本机备份”，可以删除。
- **自动备份、截图收集的设置**随配置一起迁移；Windows 游戏栏“捕获”文件夹等路径如果不同，会读取新电脑的实际位置。

## 只用命令行

不需要桌面程序时，也可以只拷贝 `<安装目录>\cli\bonfire.exe`（和同目录的规则库快照），数据放在它所在目录的 `data` 中；或用环境变量 `BONFIRE_HOME` 指定数据目录、`BONFIRE_REPO` 指定仓库。命令说明见 [cli.md](cli.md)。
