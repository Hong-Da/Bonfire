### 安装包

`build.bat --offline` 生成 `target\release\bundle\nsis\Bonfire_0.1.0_x64-setup.exe`（12.3 MB），静默安装到临时目录测试：

| 检查 | 结果 |
|---|---|
| 安装 | 成功；文件：`Bonfire.exe`（桌面应用，图形界面程序）、`cli\bonfire.exe`（命令行，控制台程序）、`manifest.json.zst`（内置规则库，23,606 款游戏）、`uninstall.exe` |
| 卸载登记与快捷方式 | “应用和功能”中登记版本 0.1.0；开始菜单“Bonfire” |
| 命令行 | `bonfire --version` 正常；读到内置规则库；数据建在 `<安装目录>\data` |
| 覆盖安装（升级） | 成功，`data` 中的仓库保留 |
| 卸载 | 程序、命令行、登记、快捷方式全部清除；`data`（配置与备份仓库）保留 |

验收中发现并修复：桌面程序 `Bonfire.exe` 与命令行 `bonfire.exe` 在 Windows 上同名（不区分大小写），安装后命令行覆盖了桌面程序。命令行改为放在 `cli\` 子目录，与桌面程序共用 `<安装目录>\data`，并能读到安装目录中的内置规则库。

## 二、用户验收（请在本机安装后逐项确认）

安装：运行 `Bonfire_0.1.0_x64-setup.exe`。安装前请先关闭开发版（`pnpm tauri dev` 启动的篝火）：两者标识相同，同时运行时只会打开其中一个窗口。

> 注意：恢复会改写真实存档目录（恢复前自动生成保护快照，可一键撤销）。建议先找一个不在意的游戏，或在完成一次备份之后再试恢复。
