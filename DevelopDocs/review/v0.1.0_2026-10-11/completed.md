# 已完成的功能

- 项目名称：篝火 Bonfire
- 当前版本：0.1.0
- 盘点日期：2026-10-11
- 比较基准：原始任务文档 `DevelopDocs/游戏存档备份软件 · 开发设计文档.md`（第一次盘点）

功能分类（与测试 skill 的功能清单一致）：GAME 游戏管理与发现、SCAN 更新检测与状态、BAK 备份、HIS 历史 / 分支 / 标签 / 备注、RES 恢复与撤销、XFER 导入导出、SHOT 截图、AUTO 自动备份与运行检测、CLEAN 历史清理、SEC 加密与被占用文件、MAINT 仓库维护与规则库、UI 桌面界面。

测试情况取自 2026-10-11 最近一次全量测试：应用服务层 116 个、核心库 59 个、存档发现 40 个单元测试，CLI 用例 163 条（`tests/cases/cli_cases.toml`）、崩溃一致性测试、文档测试，前端 Vitest 103 个，全部通过；clippy 无警告。用户本机验收清单（`docs/acceptance/M3-acceptance.md`、`M4-acceptance.md`）尚未确认，见 `pending.md`。
