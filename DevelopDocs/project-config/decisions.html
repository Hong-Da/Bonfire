U-45a

7z 或 rar 压缩包能不能内置解压

默认推荐
  • 都内置：7z 用纯 Rust 的 sevenz-rust2，rar 用 unrar（内含 RarLab unRAR 解压源码），都支持加密（推荐） ✓ 采用
  • 只内置 7z，rar 仍提示先解压
  • 调用用户电脑上已安装的 7-Zip

理由网上存档包大量使用 7z 与 rar；内置后用户无需另装工具。rar 没有可靠的纯 Rust 实现。

影响新增依赖：sevenz-rust2（Apache-2.0）、unrar（MIT/Apache，含 unRAR 许可的 C++ 源码，只能解压、不得用于做 RAR 压缩器；发布时需在第三方声明中列出）；构建需要 C++ 编译器（Windows 构建环境已有）。

按修改时间判断“手动替换”的误判

默认推荐
  • 只看被修改的文件；同一文件时间倒退，或被修改的文件都早于上次备份时提示（推荐） ✓ 采用
